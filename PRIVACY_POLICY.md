# Privacy Policy for Next AI AutoPublisher

**Effective Date:** August 2, 2026  
**Developer:** HanifKhan9794  
**App Name:** Next AI AutoPublisher  

Next AI AutoPublisher ("we", "our", or "us") is dedicated to protecting your privacy. This Privacy Policy explains how our application handles data when connecting to third-party services, including the Pinterest API (v5).

## 1. Information Collection and Use
Next AI AutoPublisher is a personal/creator content scheduling tool that generates short-form video content and publishes it to the authenticated user's Pinterest boards. 
- We **do not** collect, store, sell, or share any personal data of Pinterest users ("Pinners").
- We process OAuth 2.0 access tokens strictly to authenticate requests made to the official Pinterest API endpoints.

## 2. API Scope & Data Access
- **Pins & Boards**: Our application accesses only the authenticated user's own Pinterest boards to publish user-authorized video Pins and Idea Pins.
- **Analytics**: Basic analytics data is read exclusively to confirm successful posting of authorized Pins.
- **No Third-Party Access**: We do not access, store, or profile public user data or general Pinners' information.

## 3. Data Storage & Security
- Access tokens and API secrets are stored locally in secure environment files (`.env`) on the creator's machine.
- No access credentials or user data are transmitted to external servers other than official Pinterest API endpoints.

## 4. User Rights & Token Revocation
Users retain full control over their account permissions and can revoke Next AI AutoPublisher's access at any time via [Pinterest Account Settings > Apps](https://www.pinterest.com/settings/apps).
