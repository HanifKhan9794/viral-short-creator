# Privacy Policy for Next AI AutoPublisher

**Effective Date:** August 2, 2026  
**Developer:** HanifKhan9794  
**App Name:** Next AI AutoPublisher  

Next AI AutoPublisher is dedicated to protecting user privacy. This application connects to the Pinterest API (v5) strictly to create and schedule video Pins to the authenticated creator's own Pinterest boards.

## 1. Information Collection
We do not collect, store, sell, or share any personal data of Pinterest users ("Pinners"). We process OAuth 2.0 access tokens strictly to authenticate requests made to official Pinterest API endpoints.

## 2. API Data Usage
The application accesses only the authenticated user's own Pinterest boards to publish authorized video Pins and Idea Pins. No third-party user data is harvested or retained.

## 3. Data Protection
Access tokens and API secrets are stored locally in secure environment configurations on the creator's machine.
