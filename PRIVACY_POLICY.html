Privacy Policy for Next AI AutoPublisher

Effective Date: August 2, 2026
Developer: HanifKhan9794
App Name: Next AI AutoPublisher

1. Information Collection and Usage

Next AI AutoPublisher is a personal content scheduling tool that generates short-form video content and publishes it to the authenticated user's Pinterest boards. We do not collect, store, sell, or share any personal data of Pinterest users ("Pinners"). We process OAuth 2.0 access tokens strictly to authenticate requests made to official Pinterest API endpoints.

2. API Scope & Data Access

The application accesses only the authenticated user's own Pinterest boards to publish authorized video Pins and Idea Pins. No third-party user data is harvested or retained.

3. Data Protection

Access tokens and API secrets are stored locally in secure environment configurations on the creator's machine and are never exposed publicly.
